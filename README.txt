OUTSPAN HOTEL NYERI WEBSITE — SEPARATE HTML AND CSS

Files
-----
- index.html  : Website structure and interactive JavaScript.
- style.css   : Separate stylesheet for layout, colors, typography and responsive design.
- README.txt  : These setup and editing instructions.

Preview
-------
Keep index.html and style.css in the same folder. Open index.html in a modern browser.
The page links to style.css using:
    <link rel="stylesheet" href="style.css">

Before publishing
-----------------
1. Replace the example telephone number (+254 700 000 000) with the hotel's verified front desk number.
2. Replace reservations@example.com with the correct hotel email address. Update both the visible links and the mailto recipient in the JavaScript form handler.
3. Replace all placeholder prices such as [insert rate] and [rate] with approved tariffs, or change them to “Contact us for rates”.
4. Verify service descriptions, recreation activities, conference capacities, history and offers with hotel management.
5. Replace sample video embeds with official Outspan Hotel room tours and walkthroughs.
6. Replace stock image URLs with approved hotel photography where possible.
7. The enquiry form currently opens the visitor's email app via mailto. It does not store submissions or send them to a database.
8. Test the page on mobile and desktop before launch.

Note
----
The website uses remote Unsplash images and remote YouTube embeds, so an internet connection is required for those media elements to load.
